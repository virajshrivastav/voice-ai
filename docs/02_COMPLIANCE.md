# Compliance Kit (India) — v0

Not legal advice. Reviewed against public sources on 2026-09-06 (see `01_EVIDENCE_CHECK.md` #25–#34). Get a lawyer's sign-off before Stage 3.

## 1. Hard rules baked into the product
1. **Verbal AI disclosure in the first 10 seconds of every call**, in the call language, in the cloned voice itself. Never skippable, never shortened. Exact text in `03_CALL_SCRIPT.md` (OPEN turn).
2. **Consent before cloning.** No voice is cloned without a signed + recorded consent from the speaker (template §3). No public figures, no third parties, no "test" exceptions.
3. **Opt-out at any point** ("नाही/नहीं/no/stop") → immediate polite close + number added to `optout` table + never dialled again by any campaign.
4. **DND / preference check** against the access provider's DLT preference registry before every dial batch; log the check timestamp per number.
5. **Recording notice** in the OPEN turn; recordings stored encrypted; retention period stated (recommend 180 days, then delete audio, keep structured answers).
6. **No promises, no policy statements, no attacks** generated by the LLM. LLM output is restricted to answer classification + whitelisted acknowledgements/clarifications.
7. **Dialling window** 10:00–19:00 local; no dialling on polling day, the 48-hour silence period, or days of mourning.
8. **Audit log** per call: disclosure played (timestamp + audio hash), consent reference for the voice, DLT header/template IDs, DND check result, opt-out events.

## 2. Regime-by-regime checklist

### TRAI TCCCPR 2018 (+ 2nd Amendment, 12 Feb 2025)
- [ ] Sender (Principal Entity) = **MLA's office** (decided). Register on one access provider's DLT (Airtel/Jio/Vi) — needs entity PAN/GST or equivalent, authorised signatory, letter of authorisation. Lead time 1–3 weeks.
- [ ] Register the telemarketer/aggregator (Exotel/Plivo/our own entity) as the delivery partner on DLT.
- [ ] Obtain a **140-series** number for promotional/outreach voice; ask the telco in writing whether governance-lane calls from an MLA's office qualify as "Government Voice Call"/service communication (different header class, fewer DND restrictions).
- [ ] Register call templates/headers for the scripted content.
- [ ] Honour customer preferences (DND, time bands, categories).
- [ ] Get **written confirmation from the telco** that AI-voice political/constituent outreach is acceptable use on their network.

### ECI (applies whenever MCC is in force for any election covering the constituency)
- [ ] Label: every call opens with the AI-generated disclosure (verbal). If any visual collateral is used, label ≥10% display area.
- [ ] Disclose creating entity (MLA office + vendor) in campaign records.
- [ ] **MCMC pre-certification** of the scripted audio (submit the pre-rendered turns as the "advertisement"; dynamic turns limited to clarifications/answer capture — document this design in the submission).
- [ ] No calls in the 48-hour silence period; no calls on polling day.
- [ ] Expenditure accounting to the candidate's election expense return.
- [ ] 3-hour takedown/response process for complaints.

### MeitY IT Rules Amendment 2026 (G.S.R. 120(E), in force 20 Feb 2026)
- [ ] Synthetic audio labelled (verbal) + metadata tag in stored files (`synthetic=true`, `voice_consent_ref`, `generator`).
- [ ] If any audio is published on platforms, declare it as synthetically generated.

### DPDP Act 2023 + Rules 2025
- [ ] **Data source diligence:** document where the voter list + per-voter info came from and the legal basis. Publicly available electoral rolls (Form 20/PDF rolls) — permitted with caveats; Aadhaar, ration, scheme-beneficiary databases — **not permitted** for this use.
- [ ] Notice: itemised purpose ("constituent outreach; recording; storing your answers to improve public services; aggregated insights") delivered verbally in OPEN turn (short form) + link/SMS to full notice (long form).
- [ ] Consent to continue = voter says yes after the notice; store as consent artefact.
- [ ] Withdrawal = opt-out; delete personal data on request within stated SLA.
- [ ] Data Fiduciary = MLA's office (or the entity operating the campaign) — name it; appoint a contact for grievances.
- [ ] Security: encryption at rest, access logs, breach-notification plan.
- [ ] Retention schedule written down.

### Vendor ToS (Sarvam / Smallest / Cartesia / Exotel / Plivo)
- [ ] Consent artefact per cloned voice matches vendor requirements (Sarvam: explicit consent + enterprise onboarding; Smallest/Cartesia: consent clause in ToS).
- [ ] Never upload public-figure audio. Never upload third-party audio.

## 3. Voice-clone consent template (politician)
> मी, [पूर्ण नाव], [पद/मतदारसंघ], याद्वारे [ऑपरेटर संस्था] ला माझ्या आवाजाची कृत्रिम (AI) प्रत तयार करण्यास आणि ती फक्त [उद्देश: मतदारसंघातील नागरिकांशी संवाद] यासाठी, [तारीख] ते [तारीख] या कालावधीत, माझ्या लेखी मान्यतेने ठरलेल्या संहितेनुसार वापरण्यास संमती देतो/देते. प्रत्येक कॉलमध्ये ही AI प्रत असल्याचे स्पष्टपणे सांगितले जाईल. मी ही संमती कधीही मागे घेऊ शकतो/शकते; तसे केल्यास आवाजाची प्रत व नमुने ७ दिवसांत नष्ट केले जातील.
> सही / तारीख / साक्षीदार. + 30-second **spoken** consent recording repeating the above in the speaker's own voice.

Store: signed PDF + audio + hash in `politician.consent_*`.

## 4. Data-retention & access defaults (proposed)
| Data | Retention | Access |
|---|---|---|
| Call audio | 180 days | operator + MLA office (named users) |
| Transcripts | 365 days | same |
| Structured answers (de-identified aggregates) | indefinite | MLA office |
| Phone numbers + names | life of campaign + 90 days | operator |
| Opt-out list | indefinite (must persist) | operator |
| Consent artefacts | 7 years | operator |

## 5. What is *not* allowed in this product
- Cloning anyone who hasn't signed §3 (includes "just testing" with a public figure).
- Calls without the disclosure line.
- LLM-generated statements of policy, promises, or attacks on opponents.
- Using welfare/Aadhaar/beneficiary data for targeting.
- Dialling during silence period / polling day / outside 10:00–19:00.
